# 新增一週筆記的 Loop 規格

用法：把該週講義放進 `raw/`，然後對 AI 說「/add-lesson 第 NN 週，講義在 raw/xxx.pdf」。

## 🎯 目標
產出 `lessons/week-NN-短名.html`，並更新 `index.html`、`glossary.html`、`log.md`。

## 🚧 限制
- 只讀 `raw/` 裡這一週的講義和 `AGENTS.md`；不要參考其他網站。
- 只能新增/修改：該週頁面、`index.html`、`glossary.html`、`log.md`。
- 外框一律從 `templates/lesson-template.html` 複製。

## 🔁 每一輪做什麼
1. **讀講義** → 列出這週的：路線圖（3–7 點）、核心觀念（≥3 個）、實作步驟、新詞彙。
2. **先給我看大綱**（只列標題，不寫內文），我說 OK 才往下。
3. **寫頁面**：複製模板 → 依 AGENTS.md 5.2 的 7 個區塊填內容。
4. **更新首頁卡片**（依週次排序）和**詞彙表**（新詞照字母序插入，舊詞補週次連結）。
5. **跑檢查**：`python3 scripts/check.py`。
6. **只修檢查報告列出的問題**，然後回到第 5 步。

## ✅ 完成標準
- `check.py` 全部 ✅
- 開新的對話做 AI 審查：只給它「講義＋新頁面」，請它檢查有沒有講錯、講反、漏掉講義的重點。審查意見修完。

## 🛑 停止條件
- 全部通過 → 寫 log、commit，結束。
- 修滿 3 輪仍有 ❌ → 停下來，把剩下的錯誤列給我。
- 講義看不清楚或內容不足 → 標 `【待確認】` 並停下來問我，不要自己編。

## ⏰ 觸發
每週上完課、把講義放進 `raw/` 之後，由我手動呼叫。
